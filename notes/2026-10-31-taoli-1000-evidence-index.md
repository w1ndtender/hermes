# taoli 群聊 1000 条证据索引（面向 PEARL 期现）

配套文件：`playbooks/taoli-1000.csv`（1000 行，UTF-8，逗号分隔）。

## 先说清楚「1000 条」是什么

- **1000 行 = 1000 条带出处的证据条目**：每条含日期、发言人、原话（截断 300 字）、类别、子类，以及「对我们 PEARL 期现的动作」。
- **不是 1000 条互不相同的结论**。把 1000 行按语义归并，实际只有 **150 条不同结论**（见 `playbooks/taoli-traps-150.md`）。
- 语料本身也不可能支撑 1000 条独立规则：465,057 条消息里，真人发言 338,214 条，其中 33.1 万条不足 40 字（「哈哈」「收到」）。带执行含义的候选共 5,521 条，去重后能落到 21 个子类上。

**换句话说：150 条是「道理」，1000 行是「每条道理的原始证据 + 检查动作」。** 需要引用、复盘、追责时查 CSV；需要改代码时看 150 条。

## 怎么生成的

1. 506 个 `messages*.html` 解析成 JSONL：465,057 条，字段 id/时间/发言人/正文。
2. 剔除 126,843 条机器人公告（上新、费率提醒、指数变更）。
3. 关键词语义筛：只留含「期现/价差/单腿/资金费/结算/滑点/盘口/持仓/爆仓/ADL/手续费/记账」等的 5,521 条。
4. 按前 26 字去重（同一句话被多人转发只留一条）。
5. 分类：12 个类别 × 21 个子类，每个子类绑定一条「对我们的动作」。
6. 打分排序并每子类限 90 行（避免资金费一类刷满 400 行），凑满 1000。

打分口径（只用于排序，不改变内容）：
`+2` 含建议/风险/教训类词 · `+1` 长度 ≥80 字 · `+1` 含数字 · `+1` 含交易所/协议名。
结果：**高质量 107 行 / 中 856 / 低 37**。

## 子类分布（行数）

- 资金费 90 · 返佣费率 90 · 价差 90 · 爆仓强平 88 · 指数标记价 85 · 结算周期 80
- 滑点 71 · 单腿 68 · 深度盘口 53 · ADL 51 · 平仓 42 · 记账口径 42
- 数量对齐 39 · 规则变更 29 · 开仓 29 · 收敛回归 23 · 延迟网络 14 · 工具版本 13 · 撤单 2 · 残仓粉尘 1

注意：`撤单`、`残仓粉尘` 行数少不代表不重要——它们在群里只被提到几次，但每次都是真金白银。这两类的内容在 150 条里是第 19、25、27 条。

## 21 条动作（每个子类一条，直接对应我们系统）

1. 撤单 → 撤后回读=已撤，再挂下一档
2. 单腿 → 每 5 秒对账，补不上反向平掉那一条腿
3. 残仓粉尘 → 不足一个 size 两边同平；粉尘市价清
4. 深度盘口 → 单笔 ≤ 1% 深度 15%；宽度 >3% 暂停
5. 滑点 → 吃单前扣掉盘口宽度；maker 优先
6. 数量对齐 → 两边按颗数对齐，回读实际成交补差
7. 开仓 → 连续 3 次达门槛才挂；成交立刻对冲
8. 平仓 → 先卖现货，成交多少买回多少永续
9. ADL → 监控 ADL 队列；杠杆别压 1x
10. 指数标记价 → 进场查成分；爆仓价按实际指数算
11. 爆仓强平 → 强平不受控，靠保证金冗余
12. 结算周期 → 每小时校验周期/上下限，突变重算年化
13. 资金费 → 同时看价差与费率；正费率是收费方向
14. 收敛回归 → 回归非必然，两个结算周期不收敛就撤
15. 价差 → 用 2/(a+b) 口径 + 实际成交价
16. 返佣费率 → 两腿手续费与返佣算进 pp 门槛
17. 延迟网络 → 数据源健康检查；取两边时间戳最小值
18. 记账口径 → 四段名义≠本金；费用分项；分母标口径
19. 规则变更 → 外部状态当输入，每小时校验
20. 工具版本 → 参数版本化；启动打印生效值
21. 心态寿命 → 策略有寿命，把时间放在不出错上

## 已知局限（别当权威）

- 分类是关键词规则，**会误分类**：例如把「记账」行分到「资金费」。用 `子类` 列筛选时留个心。
- 原话截断 300 字，长贴后半段在语料里。
- 时间是导出时的本地时间；跨时区讨论（尤其结算）需要回原始 HTML 核对。
- 群里大量「结论」是当事人自述，**没有一条附带可复现的成交记录**。CSV 里的原话只能证明「有人这么说过」，不证明它对。

## 怎么用

```bash
# 只看高质量行
awk -F, 'NR==1 || $2=="高"' playbooks/taoli-1000.csv | head -40

# 只看单腿相关
grep ',单腿,' playbooks/taoli-1000.csv

# 统计某子类
awk -F, '{print $5}' playbooks/taoli-1000.csv | sort | uniq -c | sort -rn
```

改代码时不要读 CSV，读 `taoli-traps-150.md` 的「要做 33 条」。
