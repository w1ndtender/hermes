# Agent Wallet 赚钱：有账可查的案例 vs 口号

信源分三级：**一手**（合约/官方公告/带完整流水的复盘）> **二手**（KOL 复盘带数字）> **三手**（转发、口号、"人均 XX 刀"）。

## 一、唯一可用作基准的真实案例（一手，带完整流水）

**ruuo.de《第一次用AI钱包：四枚NFT，赚了约41U》**（2026-10-22，Ptah Relics）

完整 P&L：

| 项目 | 金额 |
|---|---|
| 4 枚卖出总额 | 55.8400 USDT |
| 市场手续费 | 0.5584 USDT |
| 卖出净回款 | 55.2816 USDT |
| 铸造成本（含 BNB 折算） | ~14.2562 USDT |
| 全部链上 Gas | ~0.0700 USDT |
| **最终净收益** | **~40.96 USDT** |

关键机制（这段比收益数字重要）：
- **每个 Agent ID 累计最多 4 枚**，第一枚有优惠，后三枚按正常价
- 利润来源是**铸造成本 < 市场即时买单价**，不是"装好钱包就到账的奖励"
- 他有**一张买单在出售时已失效**，模拟失败 → 换单重试，没有强提交
- 授权是**逐枚 NFT 授权**，没给全局权限；事后核对授权已归零
- 出售需先给市场合约转移权限，**授权和成交之间有时间差**

→ 这单的真实利润率：40.96 / (14.2562 + 0.07) ≈ **2.86 倍**，但**依赖二级市场有买单**。

## 五、从证据里得出的结论（不是口号）

1. **能算的只有"成本"**：mint 成本 + gas 是确定的；卖出价是不确定的
2. **每个案例的利润都来自"有买单"**，不是协议发钱 → 任何"稳赚"都要问一句：**谁在买？**
3. **上限决定天花板**：每 ID 4-5 枚 × 单枚利润 10U 级别 = 单号几十 U 量级，想要规模只能多号
4. **失败模式是"授权了但没成交"**，不是"被盗" —— 所以流程里必须做模拟 + 逐枚授权
5. 已经铸完的项目（Ptah Relics）**不再有 mint 机会**，只能等下一期
