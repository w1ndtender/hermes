# Agent 赛道地图 · 2026-10-27

信源：X 实时搜索（@SauravY79514198），均为公开推文；括号内是发帖人。未逐条链上验证的标「待核实」。

## 一、核心逻辑

币安 Agentic Wallet 的 `.ai` Agent ID 成了准入门票：**没有 ID 的普通钱包进不去**这些平台。
所以当前阶段的机会不是「猜币」，而是「用 ID 去领/去 mint 低成本资产」，赌后续快照或二级市场。

## 二、平台清单（按成本从低到高）

### 1. Ptah — Proof of Agent (POA)
- 灵魂绑定卡，**每个 Agent ID 免费领一张**（@vkf1785187 教程，@bold_dc7195 等大量用户在晒 Agent #32869 / #32986）
- 社交挖矿：**10/26–11/9 共 15 场**，每天发帖参与 PTAH 抽奖
- 有人说「人均 45-50 刀空投」（@liushurong1）→ **待核实**，属引流措辞
- 入口：`ptah.trade/poa`

### 2. Ka Agents — agentka.xyz
- 首张免费；第 2 张起 50 PTAH（≈0.015u）；**每 ID 上限 5 张**；总量 6,666（@ibtc2023）
- 官方 @kaAgents；自带市场，方便出货（@Ouh_web1）
- 发帖时参与地址仅约 226 个 → 极早期

### 3. Coracle Agents
- 总量 10,000；**前 2 张免费（只付 gas）**；之后每张 0.0005 BNB（≈$0.37）；每钱包上限 10（@cheapskate_01）
- 实测 gas：约 **0.0000077 BNB/张**（@MmlFf43009）

### 4. gang.fun（我们在盯的）
- Agent-only 发射台：内盘 bonding curve 只允许持 Agent ID 的钱包买入（@0xno_fomo 教程）
- **V3 新增「铭文式打新」**（@jiahaozhong26559）：
  - 固定价格分份 mint
  - 打满自动发射
  - **开盘价 = 打新价**
  - 打满前可原价撤出
  - 单地址有上限
- 官方进度：@0xLazy 说 **V3 当天延期**（"V3 slips today"）；@0xawufdc 称大家仍在蹲当晚
- 平台币 $GANG 市值约 8M（峰值 10M）

## 四、判断

- 这类 mint 的**成本几乎为零，风险在时间**（要盯、要领、要做任务）
- 「空投多少刀」的说法基本是引流，**不要按预期收益决策**，按成本≈0 去做即可
- gang V3 是唯一有真实成本（gas + 份额）的玩法，也是唯一有明确开盘价机制（开盘价=打新价）的，赔率清楚
