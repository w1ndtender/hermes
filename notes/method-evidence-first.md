# 学习方法：怎么学才「有用」

问题不是学得太少，是**学了不能变成动作**。这份是给「撸毛 / 打新 / Agent 赚钱」这类高噪音领域定的规矩。

## 一、信源分级（强制标注）

| 级别 | 例子 | 怎么用 |
|---|---|---|
| 一手 | 合约源码、官方公告、**带完整流水的复盘** | 当事实，可作决策依据 |
| 二手 | KOL 复盘有数字但没流水、链上浏览器数据 | 当线索，需交叉验证 |
| 三手 | 转发、"人均 XX 刀"、"稳赚" | **只当情绪，不进决策** |

规则：写笔记时每条结论后面必须跟一个级别标记。写不出来的，就是没验证。

## 二、只记「可执行单元」，不记故事

一条有用信息必须能填进这四格：

1. **成本**：多少 BNB / USDT，含 gas
2. **上限**：每个号能做几次、总量多少
3. **退出路径**：卖给谁、多久能卖、有没有买盘
4. **失败模式**：什么情况下会亏、会卡住

填不满四格的，就是噪音。像"XX 项目很火"这种，直接丢。

## 三、反向搜索（防幸存者偏差）

- 每个热门项目，**必须搜「亏」「跑路」「撤单」「失败」**
- 找不唱多的声音：像 @abaddoninc 骂 gang、airdropbuzz 标 Ptah「unverified」
- 只有正面案例 = 样本被筛过 = 不可信

## 四、数字自洽校验

交叉比对两个数字，看能不能对上：

> Ptah：95,000 枚 ÷ 24,444 个 ID ≈ 3.9 枚/ID，而规则是「每 ID 上限 4 枚」 → **自洽，可信**

对不上的，标「待核实」，不写进结论。

## 五、时间盒 + 产出物

- 每轮调研 **20–30 分钟**，到点必停
- 产出必须是 **playbook**（能照着做的清单），不是「摘要」
- 没产出 playbook = 这轮白学

## 六、先预测，再验证（唯一能提升判断力的动作）

动手前写下：
- 预计成本
- 预计能卖多少
- 失败条件

事后回填实际值。**只记录成功案例的学习方式，永远学不会判断力。**

## 七、外置记忆

- 过程性知识 → skill（下次自动加载）
- 结论与数据 → 仓库（可回滚、可对比）
- 不要靠"我记得"

## 八、每轮学习的检查清单

```
[ ] 有没有一手证据（带流水/合约/官方）
[ ] 四格填满了没（成本/上限/退出/失败）
[ ] 搜过反面了吗
[ ] 数字自洽吗
[ ] 产出是可执行的 playbook 吗
[ ] 有没有写下可被证伪的预测
```
