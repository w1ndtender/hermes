# 12 零成本监控：不花 token 也能盯

## 三种不烧模型的做法
1. **cron 脚本模式（no-agent）**：`--script` 跑脚本，stdout 原样投递，零 LLM。
   抓数据、算指标、健康检查、对比价格，全走这条。
2. **watchdog 插件**（社区 `hermes-watchdog`）：后台跑轻量 checker（GitHub / RSS / 网页），
   **只有内容变了才通知**，空闲时不消耗 token。适合盯公告、盯仓库、盯网页改版。
3. **webhook 触发**：外部事件（PR 评论、服务告警）直接触发 cron，不靠轮询。

## 我们的用法
- 链上/看板抓取 → 脚本模式，输出「有货才打印」。
- 价格/价差阈值 → 脚本判断，命中才输出一行。
- 模型只在「要不要做、为什么、怎么做」这种判断上出场。

## 反例（我们踩过）
用 agent 模式跑每 15 分钟的扫描：每次都读系统提示 + 工具表 + 历史，贵且容易跑偏，
还会因为模型理解差异给出不同结论。同一个判断，不同轮次结论不同 = 不可回测。
