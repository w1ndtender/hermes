# 15 配置速查（`~/.hermes/`）

## 目录
```
config.yaml   设置（模型、终端后端、压缩、TTS…）
.env          API key（`hermes config set UPPER_SNAKE` 会自动写这里）
auth.json     OAuth 凭据
SOUL.md       身份（系统提示第 1 槽）
memories/     MEMORY.md、USER.md
skills/       skill_manage 管理的技能
cron/         定时任务
sessions/     网关会话
logs/         errors.log / agent.log / gateway.log（密钥自动打码）
```

## 常用命令
```
hermes config                 # 看全部
hermes config get <key>
hermes config set <key> <val>
hermes config unset <key>
hermes config check           # 缺项与过期选择
hermes config migrate
```

## 「变笨了」三步排查（官方顺序）
1. `/model` 看当前模型是不是你以为什么（切换默认只对当前会话生效；dashboard 改的只影响新会话）。
2. `/usage` 和 `/context` 看上下文占用（系统提示 / 工具 / 技能 / 记忆 / 对话各占多少）。
3. 上限不对就直接看启动行的 context length。

退化时的处理：`/compress`（可加 `here N` 保留最近 N 轮、`focus <主题>` 指定摘要重点），或 `/new`。
会话中途换模型会**重置 prompt 缓存**，长会话里可能比直接开新会话更贵。
