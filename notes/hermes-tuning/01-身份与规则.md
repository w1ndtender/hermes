# 01 身份与规则：SOUL / AGENTS / 记忆

## 三层各管什么（官方口径）
- **SOUL.md**（`~/.hermes/SOUL.md`）：身份、语气、怎么处理不确定与分歧。**不放**路径、命令、端口、项目流程。
- **AGENTS.md**：项目级规则、目录结构、约定、坑。按目录链加载（git root → 工作目录）。
  - 优先级：`.hermes.md` → `AGENTS.override.md` → `AGENTS.md` → `CLAUDE.md` → `.cursorrules`，**每会话只加载一种项目文件**。
  - 个人覆盖用 `AGENTS.override.md`（通常 gitignore），不动仓库里的 `AGENTS.md`。
- **记忆**（MEMORY.md 2,200 字符 / USER.md 1,375 字符）：跨会话的长期事实与偏好，不是任务日志。

判断标准一句话：**到处都适用的进 SOUL，只属于某个目录的进 AGENTS，跨会话的事实进记忆**。

## 记忆的两个硬机制
1. **冻结快照**：系统提示里的记忆是会话开始时抓的，会话中途写入只在**下个会话**生效。
2. **不会自动压缩**：写超了直接报错，必须自己合并或删——所以别把临时信息塞进去。

## 常见错法
- SOUL 里塞项目细节（我们犯过）。
- 记忆塞满琐事（我们犯过，98%）。
- 想让 agent 记住某条流程 → 应该写成 skill，skill 只在用的时候加载，不占记忆额度。
