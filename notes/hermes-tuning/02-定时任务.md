# 02 定时任务（cron）

## 模型解析顺序（官方）
**单任务钉 → `cron.model`（config.yaml）→ 当前主模型**。
不钉就会跟着你聊天换的模型跑 —— 换供应商时任务可能静默死掉。

```
hermes config set cron.model <model>                 # 全队默认
hermes cron create/edit --model <m> --provider <p>   # 单任务钉
hermes cron create/edit --pin                        # 锁当前主模型
hermes cron create/edit --reasoning-effort high      # 单任务思考等级
```

## 两种任务形态
- **agent 模式**：跑一次完整会话，能思考、能调工具，烧 token。
- **脚本模式（no-agent）**：`--script` 直接跑脚本，stdout 原样投递，**零 LLM 参与**。
  → 纯监控/纯抓取/纯计算都该用这个，省钱且不会被模型带偏。

## 投递
`origin`（原会话）/ `local`（`~/.hermes/cron/output/`）/ `telegram` / `telegram:<chat_id>` / `feishu` 等。
没内容就不发：在提示里约定输出 `[SILENT]`。

## 运维命令
`hermes cron list | runs <id> | incidents | doctor | cancel <id> | pause | resume`。
`cancel` 只停当前那次，不动计划；`remove` 会顺手杀掉在跑的那次。
