# 06 交易类实战（别人怎么搭）

## IBKR 量化那位的结构
`行情 API → Python 策略引擎 → 券商网关`，Hermes 只做 cron 调度。
- cron 每 3 分钟：跑脚本、取结果、有成交才通知。
- 六个条件全过才买（RSI/布林/MA20/ADX/MACD/量能），卖出任意一个触发就走。
- 原话：「出得快比进得准更重要」。
- 必须有看板：「看不见的东西修不了」。

## 对期现/价差策略的可迁移结论
1. **判断与下单在脚本里，模型只调度播报**（模型不该每次现算价差）。
2. 进场多道闸全过，出场简单。
3. 看板要显示「为什么没触发」，不只是价格。
4. 回测/验证用脚本断言，不让模型自评。

## 别踩
- 小模型做复杂判断：看起来能用，实际判断全错。
- 用真实账户调参；先纸面跑。
