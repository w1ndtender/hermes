# 05 协作与分工

## 子任务（delegate_task）
- 默认可并行 10 个，互不共享上下文，只有最终摘要回到主线。
- 适合「10 个地址一起查」「多来源同时读」。
- 子任务**自报成功不算数**，产物必须自己验（官方也这么写）。

## 代码交给外部 agent（我们的规矩）
- Codex / Claude Code 写代码；我出规格、跑验证、对账。
- 规格书六段：目标 / 现状 / 要改成什么 / 不许动什么 / 验收命令 / 怎么回滚。
- 验收看三件事：有没有静默失败、有没有把缺失数据当 0、有没有同一算法两份实现。

## Codex CLI 在本机的接法（已验证）
```
npm i -g --prefix ~/.npm-global @openai/codex
codex login --device-auth          # 打印链接 + 一次性码
sudo apt install bubblewrap        # 沙箱依赖
sysctl -w kernel.apparmor_restrict_unprivileged_userns=0   # Ubuntu 24.04 必须
codex exec --sandbox workspace-write "按 specs/xxx.md 实现"
```
