# 11 消息排版（Telegram / 飞书）

## Telegram：Go 标准 Markdown，别自己拼 MarkdownV2
Hermes 有两条渲染路径：
- **Rich Message（默认）**：直接把原始 Markdown 交给 Telegram，表格、任务清单、折叠块、块级公式都能原生渲染；
  流式预览是「草稿 + 原地编辑」，不会重复消息。上限 32,768 字符，超了自动降级。
- **MarkdownV2 兜底**：老的 MarkdownV2 不支持表格和清单，会做十步转换。

所以：**输出正常 Markdown 即可**，不要为了 Telegram 手写转义。

## 飞书
- 支持 websocket（推荐，无需公网回调）与 webhook 两种模式。
- 群聊默认「@ 才回」，且每个用户会话隔离（`group_sessions_per_user: true`）。
- 卡片（interactive card）可用，但飞书服务端对表单/输入类组件支持不完整，会静默降级；
  复杂交互别指望它。
- 想「没内容就不发」：cron 提示里约定输出 `[SILENT]`。

## 我们的约定
买卖各留前三、一人一行、金额带单位、不要宽表格；颜色/emoji 只用于区分类型，不用于装饰。
