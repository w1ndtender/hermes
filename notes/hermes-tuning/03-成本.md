# 03 成本：钱花在哪

## Prompt 缓存是最大杠杆（同款 deepseek-flash 的生产实测）
- 命中率 98.7%；命中价 $0.003/M，未命中 $0.15/M，**差 50 倍**。
- 原理：系统提示 + 技能 + 记忆 + 工具表构成**逐字节不变的前缀**，每轮只追加小增量。
- 推论：
  - 前缀越稳越便宜。频繁改 SOUL/记忆/技能 = 下一轮从冷前缀重新付费。
  - 每个新会话至少付一次冷前缀（该实测约 47k tokens ≈ $0.007），所以长会话反而划算。
  - 真正烧钱的是**超时还在打转**的任务，不是日常聊天。

## 能省的地方
- 例行任务用脚本模式（零 LLM）。
- 例行任务钉小模型，聊天用大模型。
- 别让 agent 每轮重读整份大文件；把结论沉淀成 skill 的短条目。
