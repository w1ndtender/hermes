# 同行跟踪的设计（2026-11-02）

## 目标不是「看热闹」，是「能不能照着开仓赚钱」

所以报警只有一条硬门槛：**我们能下单的所 + 扣完成本净空间 ≥1.5% + 一轮赚 ≥$3**。
达不到就闭嘴，全部进第二天 0 点的日报。用户明确要求：别太频繁。

## 四层结构

1. **看谁**：13 个监控对象 = 看板上的 11 个还原地址 + 骨头vip5 + 共同出货口 `0x17516b91`。
   看板缩略地址用「前缀6+后缀4」在链上日志里匹配还原（UAI/USDT 转账扫一遍即可，25 个里还原 11 个）。
2. **看什么**：只认 ERC20 Transfer 日志（`eth_getLogs`）。公开索引器全封，BSC 只有 RPC 能用。
3. **怎么看懂**：拿 tx 回执把所有 Transfer 串成路径 `UAI → WBNB → USDC → USDT`，`to` 地址查已知路由表
   （OKX DEX 路由 BSC = `0x5994814f…`，已确认是这批人的主路由）。
4. **能不能抄**：链上价 vs 五所永续买一 − 成本；只在能下单的所（现在只有 Bitget）且净 ≥1.5% 时才推。

## 关键成本校准（推翻之前的 0.65% 假设）

2026-10-30 SIREN 实盘：链上买入比池中价贵 **1.82%**，卖出比中价低 0.3%，**往返 ≈2.2%**。
永续两段 0.12%，再留 0.3pp 缓冲 → **总成本 2.6%**。
含义：链上买 + 大所空，毛空间要 **≥4.1%** 才有 1.5% 净空间。之前按 0.65% 算出来的「净 3.15%」是假象。
