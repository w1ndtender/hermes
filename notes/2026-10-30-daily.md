## 结论（三条，都可直接改参数）

### 1. PRL 的 `entry_max_book_pct=1.0%` 把系统整天关死：620 个采样点里只有 9 个点能开仓（1.5%）

```
今日 ticks 620 个（10-30 00:02 → 23:30，1 分钟级）
现货盘口宽：min 0.62% ｜ median 1.80% ｜ max 4.56%
  宽 ≤1.0% 的点：25 个 = 4%
价差 ≥2.0% 的点：313 个 = 50%
两者同时满足（真正可开仓）：9 个 = 1.5%   全部集中在 20:38–20:55、22:05–22:07
```

后果（同为当日实测）：

- `exit_paused_wide_book` 触发 **732** 次（00:31–13:08），持仓期平仓被盘口宽挡掉
- `open_abort_spot_first` **33** 次（20:51–23:21，want 6.0 / got 0.0）
- 今日新开仓 **0 笔**；18:00 起 `exec_state.json` 为 `tranches: []`、`pos_size: 0`
- 日志里 watchdog 反复报"疑似刷屏：现货盘口宽 1.33%~2.63% > 1.0%，不开新仓" 130 次

**教训**：阈值不能写绝对值，要写分布分位。1.0% 是「好日子」的数字，而今天中位 1.80%。
改法二选一：`entry_max_book_pct = P20(近 7 天盘口宽)`（≈1.3%），或废掉整笔否决、改成「按盘口 1% 深度分批 + 剩下的挂单等」。

### 2. 账本 +$8.67，现金 −$0.5：价差推算系统性高估，残差 $9（24h 口径残差 −$22.05）

```
今日 close 事件 18 笔，账本累计 usd = +8.67，平掉 270.7 颗（entry_edge→close_edge 推算）
现金口径（SafeTrade USDT 1345.30→1460.08，两腿合计）≈ −0.5 USDT
24h 永续现金流：已实现 −15.63 / 手续费 −0.26 / 资金费 +1.18 = −14.71
账本同期记 +7.33 → 残差 −22.05
```

**教训**：记账只认 `HL userFills` 的 realizedPnl + fee + `userFunding`，以及现货成交回执；
价差推算（entry_edge − close_edge）只能当**上限估算**，不得进"已实现收益"。
一次放大前先看残差：> $3 就不放大。

### 3. 链上腿的真实换手是 1.82% 单边，不是 0.5% 往返；2.5% 基差实盘是负期望

```
BSC SIREN（10-30 22:05–22:11，$10 名义）
买 0.0143 BNB → 453.667 SIREN，池中价 0.02167、成交 0.022064 → 贵 1.82%
卖 451.4 SIREN → 0.014026 BNB，折 0.02174 → 比中价低 0.30%
往返 ≈ 2.2%（不含 Bitget 0.06%）；入场基差 +2.52%
净结果 −0.32 USDT = 名义的 −3.2%
```

**教训**：跨场所期现的进场门槛要写成 `基差 ≥ 往返成本 × 1.5`（不是固定 1.5%）；
当前 BAW 吃单路由 2.2% 往返 → 门槛实际是 3.3%，而今天全市场基差中位只有 2.62%（1,271 个点）。
要把这条路走通，只能压成本：自建 v4/Pancake Infinity 路由 calldata，或现货腿换同所 API（0.1%）。
