## 一、12 条改变判断的教训（带原文证据）

1. **单腿有三种「静默」形态，我们只知道第一种。**
   - bundle 成功却判成失败 → 跳过 B 腿（2025-09-02 Aliez）：`club48 bundle 查询频率超过限制，我就无法判断这个 bundle 到底有没有成功`；
     现方案改为「失败后回查 tx，bundle 成功能瞬间查到，失败要查很久」。
   - 只有黄色 warning，不报 error（2025-06-08 Younes）：`单腿不报错……是有黄色 Warn 的，就是 transaction replaced`。
   - 单腿后合约被平、现货还在、**pnl 里没有记录**（2025-12-04 Winnie）。
   → 对账基准只能是**两家交易所的持仓 + 未成交挂单 + 最近成交**，不能是 pnl、不能是请求返回码。

2. **借币利息是币本位，币价涨一倍利息就涨一倍。**
   2025-05-03 ggbone：`借了 2200 个，每天利息 8 个币……10 天后币价涨到 10u，资费还是 300u，还币要 800u，血亏`。
   解法同人：吃到资金费就拿一部分按当时币价买币还息；VigorVitae 补充「开多头锁币价」。
   → 我们不做借币，但**现货腿的币价风险不会因为「有对冲」而消失，只有数量严格相等才消失**。

3. **交易所会在你持仓时改资金费周期和上下限。**
   2026-07-15 小e：`自 2026-07-15 00:15 起，SKHYNIX/SAMSUNG/HYUNDAI 永续资金费率结算频率从 8h 调整为 4h，上下限调整至 ±0.50%`；
   同日同类公告：ARIAUSDT 8h → 4h。
   → 年化、持仓收益、门槛判断都要用「当前生效的周期与限幅」，且要**每小时校验一次外部状态**。

4. **爆仓价由指数成分决定，成分可以被挑着打。**（私库先前只有 HL oracle 权重一条）
   - Gate LA 2025-06-04：kucoin 被塞进指数 → 2000 刀在 kucoin 拉盘 → 社区 40+ 人爆仓、人均 3 万刀；
     Gate 客服结论「撮合与爆仓机制按指数价格规则正常执行，不在赔付范围」（澳里澳）；
     维权成本：新加坡律师 + 报案 ≈ 6000U，且不保证成功（xiaohai）。
   - Bybit 标记价被操纵（SERAPH），Li 被 ADL 亏 7 万刀。
   - 硬判据（Li）：`以后最好检查合约指数成份，包括 kucoin 的就不做了`。

5. **ADL 触发条件已经不是「风险基金归零」。**
   2026-01-06 ggbone：`大部分交易所改成当风险保障基金低于某阈值（从基金高点回落 x%）就触发 ADL，所以频率越来越高`；
   2025-08-09 小e：`aster 妖币只能 1-2x 杠杆，多单也是 1x，所以他不能自爆 ADL 你`；
   `插针完如果有巨大价差都可以套，这时候是吃尸体的阶段，利润来源你的前辈`。
   → 空单的 ADL 风险和杠杆档位绑定；3x 以上不要谈安全。

6. **正滑点与分佣是可计算的成本项。**（私库完全没有）
   OKX DEX 文档口径（2025-08-25 群内转述）：多数链分佣上限 **3%**，Solana 每笔最高 **10%**；
   Solana 上集成方最多可保留 **10% 的正滑点盈余**；
   2025-10-23 Aliez：`把 OKX DEX API 分佣比例设为 0.0000001%，以绕过正滑点费用`。
   → 我们在 BSC 用 OKX v6 未传 commission，BSC 正滑点 100% 返还，暂不受影响；**换 Solana 腿前必须先算这一项**。

7. **残仓要用「两边同平 + idx 去抖」，不是慢慢补。**
   2025-08-10 ⌛️：`不满足一个 size，直接两边平仓。同时记录一下 idx，下一个带 size 的 idx 进来才允许两边平`。
   → 我们 `reconcile_spot_gap()` 每 5 秒补，缺的就是这两条：粉尘不许留、补单不许跨轮次反复触发。

8. **行情时效是硬约束，不是「差不多」。**
   2025-09-01 neal：`单边价格是 15 秒之前的，或者双边价格都是 5 秒之前的`——这就是抖动与假价差来源。
   → ticks 必须存两边各自的交易所时间戳，判价差时取「两边新鲜度较差者」。

9. **容量上限决定天花板，分散是唯一的扩容方式。**
   2025-08-02 cjsjebf：`不同标的都有不一样容量上限，如果他把 10wu 分成 1000 份、一份 100u 去开所有币种……是有可能的`。
   → 我们只做 PEARL，天花板 = 一个盘口的深度（1% 内 1,695 颗）。想放大不是加杠杆，是加标的。

10. **交易所被逆向时会卡提现。**
    2025-10-10 Li（Bitget）：`他们自己被逆向了，突然新开七八千 WU 仓位，三四分钟后少一半，然后提现就卡住一个多小时`。
    → 现货腿在交易所的币不是随时可提。我们所内（SafeTrade 现货 + HL 永续）暂时不涉及跨所搬运，所以这条现在是「不要轻易改成跨所搬砖」的理由。

11. **执行细节三条**（都来自 Aliez 的产品说明，可直接映射到我们的配置）
    - `MaxA 只限制 A，不限制 B`，且因请求延迟可能超出一两单；
    - 2026-03-10 改版：`不填 VA 时 A 下市价单，其余情况 A 下限价单`；
    - `tt 是监控 A 和 B 的差价，达到就下单；新产品是监控差价下单 A，然后监控 A 的仓位变化，B 跟上，不看差价`。
    → 第二种（B 跟随 A 的实际成交）正是我们 `reconcile_spot_gap` 的思路，方向对。

12. **以损定仓 > 按价差止损。**
    2025-10-07 VigorVitae：`开仓前先问自己 K 线到哪里就要止损、愿意亏多少钱，然后拿这些钱去开逐仓`。
    我们现在的止损是「价差反向 6%」，换成金额口径更稳（6% × 名义 = 实际亏损，随价差波动漂移）。

## 二、和私库对照：9 条查漏补缺

| # | 群聊教训 | 私库现状 | 落地动作 |
|---|---|---|---|
| 1 | 单腿三形态（bundle 误判 / 黄色 warn / pnl 无记录） | 只有「单腿是最大操作风险」一句 | `exec.py` 失败原因分类留档；对账以持仓为准 |
| 2 | 指数成分可被挑（Gate LA、Bybit SERAPH） | 只有 HL io:PRL oracle 权重 | 进场前查指数成分；含小所/单所权重 >50% 降档 |
| 3 | 资金费周期与上下限会被中途改 | 只有「两层限幅」公式 | 每小时校验外部状态，突变即重算 |
| 4 | ADL 触发改为「基金从高点回落 x%」 | 有 ADL 提法，无触发条件 | 记录杠杆档位与 ADL 关系；>3x 不做 |
| 5 | 残仓「两边同平 + idx 去抖」 | 有「残仓单列」记账口径 | 加执行纪律，不只记账 |
| 6 | 正滑点 / 分佣 3%（BSC）、10%（Solana） | 无 | 换链前必算；BSC 现状记「已受保护」 |
| 7 | 行情时效要按两边各自时间戳取 min | 有「行情时效」提法 | ticks 存双边时间戳 |
| 8 | 交易所被逆向时卡提现 | 无 | 记为「不要轻易改跨所搬砖」的理由 |
| 9 | 以损定仓 | 6% 价差止损 | 改为金额口径 |

**已经被私库覆盖、不需要再加的**：价差 pp ≠ 钱、盘口宽是成本、同名 ticker 假信号、
资金费是预测不是账单、展示价差先于资金到账消失、四段名义 ≠ 本金、单腿每 5 秒对账。

## 三、这份群聊里**没有**的东西

- 没有一个人给出可复现的收益曲线：晒的都是单笔（`Expected net: +266 bps`、`Realized: +$4.23`、`+261.4 bps / Hold 2m`）。
- 没有稳定参数：门槛、size、止损全靠人肉调，且每条规则后面都跟着「会被插针打穿」的抱怨。
- 没有「无风险」：所有盈利叙事都建立在「对手盘是新手/被迫平仓/参数被改之前」上。
- 本质：**他们卖的是工具和返佣**（VIP0 $5K 免费 → VIP6 $5M $1920/月，返佣 20–66%），
  群里赚钱的人和亏钱的人用的是同一个工具，差别在资金、号码数量与对冲纪律。

## 四、对我们 PEARL 期现的直接含义

1. 我们的 3.0% 门槛本质上就是「插针后的尸体阶段」入场——只在**恐慌造成的价差**里成立，不是常态；
   今天 45 秒没成交、价差 2.3–2.9% 徘徊，是正常的，不是系统坏了。
2. 真正的风险不是价差反向，是第 1、2、4 条：单腿静默、指数成分被改、ADL。
   这三条都不在我们的 6% 止损覆盖范围内。
3. 想扩容只有两条路：加标的（第 9 条），或者降低单笔成本（maker 化，已在做）。
   加杠杆只会放大第 4 条的风险。
4. 记账口径要补：失败原因分类、资金费结算历史、双边时间戳。
