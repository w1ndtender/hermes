# 评估集（Eval Set）— 10 题

用途：每次改完规则/技能，跑一遍这 10 题，答案退化就回滚。
判定标准写在每题下面，不依赖"感觉"。

---

**E1. 一个免费 mint，每 ID 上限 5 张，只有群友在传，没有二级市场。打不打？**
✅ 只领免费那张，不做付费张。
判据：无二级市场 → 不满足"地板价 > 2 倍成本"。

**E2. ptah.trade/poa 的卡，官方背书、免费、有二级流通。打不打？**
✅ 打，每 ID 1 张，成本只有 gas。
判据：免费 + 官方 + 有买盘 → 三条全过。

**E3. gang V3 第一盘打完后，1 小时成交量 0.3 BNB。第二盘打不打？**
✅ 不打。
判据：低于 1 BNB 阈值 → 停手（见 `2026-10-27-gang-liquidity.md`）。

**E4. 有人说"人均 45-50 刀空投"，但没有任何流水。怎么记？**
✅ 标三手信源，不进结论；只作为待核实线索。
判据：无一手证据。

**E5. 某项目 24h 成交量 3 BNB、持有人 200、进度 20%。值不值得追？**
✅ 不值得重仓；单笔不超过 gas 级别，不当作收益来源。
判据：池子太浅，进出都会砸盘。

**E6. Codex 会不会明天重置？**
✅ 不给确定答案；给"距上次 X 天 + 近 7 天间隔 + 48h 基础概率"，并指向 @thsottiaux 与 Usage 页。
判据：不可预测，只给概率与数据源。

**E7. 一个 Agent ID 钱包余额 0.03 BNB，要打 3 个盘，每盘 0.0016 BNB。够不够？**
✅ 够（0.0048 < 0.03），但要预留 gas，且设总预算上限。
判据：成本可算，预算先行。

**E8. 一个 mint 需要「全局无限授权」才能参与。做不做？**
✅ 不做，或改用逐枚授权；无逐枚选项则放弃。
判据：授权面 = 风险面（ruuo 案例只做逐枚授权）。

**E9. 打新成功后要不要马上卖？**
✅ 先看买盘：有地板且地板 > 2 倍成本 → 分批卖；无买盘 → 别指望，按亏损处理。
判据：卖得掉才算赚。

**E10. 我把一个判断说错了，你应该怎么处理？**
✅ 立刻 patch 对应 skill，并在仓库记一条"错在哪、新判据是什么"。
判据：错误必须变成规则，否则等于没发生。

## 跑分方式

每次改动后，逐题给出答案，对照 ✅。低于 8/10 说明改坏了，回滚。
