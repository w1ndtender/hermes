# 免费 Mint 猎人手册（@drjingle「洪七公打狗棍法」实测版）

来源：https://x.com/drjingle/status/2115016311516586037 （2026-10-27，3,212 浏览）
作者战绩：**64 个 NFT 系列 / 70 张免费 NFT**，仅今天打了 **12 个免费**。

## 一、总原则

> 只打免费的。付费的、供应数量不清楚的、可改价或已关闸的、有明显授权陷阱的，**都会停下来等人拍板**。

## 二、六步硬筛（可自动化）

| # | 检查项 | 阈值 / 条件 |
|---|---|---|
| 1 | mint 报价 | **必须 = 0**（只付 gas）。同一合约的付费档不自动冲 |
| 2 | 剩余供应（已知 maxSupply） | 剩余 **≥100** 且 **≥上限的 20%** |
| 3 | 剩余供应（只知免费名额） | 剩余 **≥200**；**测不清 → 拦截** |
| 4 | 合约 | 最好已验证；拒绝要私钥、不明无限授权、典型引流骗局 |
| 5 | 合约权限 | 若 Ownable 或暴露 `setPrice` / `setMintOpen`：**仍须现价 0 且供应宽松**，否则报告等人 |
| 6 | 执行顺序 | 拼好 calldata → `baw contract-call preview` 看模拟/授权/扣费 → **人工确认** → `execute`。付费、供应不清、预览异常 → 停 |

**红线**：不要"先 execute 再说"。

## 五、作者的判断（重要）

> 门槛降下来以后，未来的差别会集中在三件事：**速度**（信息到 preview 的链路有多短）、**解谜**（网页算力不够时能否本地破题）、**风控规则**（谁更敢自动、谁更稳地拦截）。
> **比的是谁更稳，不是谁更贪。全员同一扳手时，乱点执行的人最先付学费。**

## 六、我们的落地规则（结合自身教训）

1. **免费档自动打，付费档一律停**（我们 10-27 打 fair mint 亏 $0.08 就是反例）
2. **供应测不清 = 不打**（宁错过，不接盘）
3. **preview 必看**：模拟结果、授权范围、扣费是否为 0
4. **退出路径优先**：有二级市场且有成交量的才碰（对应我们「没买盘=卖不掉」的教训）
5. **风控设置是隐形门槛**：BAW `abnormalTxnHandling=AutoReject` 会静默拒绝交易，必须改成"需确认"
6. **数量>单笔金额**：64 个系列 → 70 张卡，靠的是频次而非重仓
