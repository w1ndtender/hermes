## A. 建仓与下单（1–12）

1. **别在价差刚出现就冲** — neal：「开始见了价差就冲，后面发现亏的很，就加入确认窗口，确认价差真实存在以后再冲」→ [已做] 我们每 5s 重读盘口，但缺「连续 N 次都在门槛上」的确认窗口，[要做] 改成连续 3 次 ≥ 门槛才挂。
2. **DEX+CEX 的 pair 禁止同时下单** — neal：「加一个限制, 不要允许同时下单，因为忘记改这个，单腿亏了好多次」→ [已做] 我们顺序下单。
3. **下单数量要按「币数」对齐，不是按美元对齐** — VigorVitae：+A 1000 / −B 1100 时两腿不等，只能手动补 → [要做] 我们 `entry_slice_usd` 是美元口径，改成分档后回读两边实际颗数再补差。
4. **minA / minB 填错方向（负数）会静默不开仓** — AA 2026-07：「minA 配置错了，应该填负数…−10 反向了，还被扣资费了，醒来 +2 发现不对劲平了，一毛没赚」→ [知道] 我们用的是自己写的执行器，但同类错误=参数符号错，校验要做。
5. **下单量要按盘口深度切，不是按本金切** — cjsjebf：「不同标的都有容量上限，把 10wu 分成 1000 份 100u 开所有币种」→ [已做] 20 颗/笔 ≈ 1% 深度 6%。
6. **拆单只在深度不够且有人接着挂时才成立** — VigorVitae 两种说法并存：小 size 反复 loop 能每次重检机会，但「深度够时不如一笔大单」→ [已做] 我们 1% 内 334 颗，20 颗/笔是折中。
7. **挂单 45 秒不成交就撤，不追价** — 群里多次：「挂 50 分钟零成交」的自我吐槽 → [已做] `spot_maker_wait_s=45`。
8. **同一价位不要反复撤挂** — 撤挂丢排队优先级，且撤单不一定成功（见 13） → [已做] 同价复用挂单。
9. **吃单前算清盘口宽度** — 现货买卖价差 1.36% 时吃单等于先亏 1.36% → [已做] maker 优先，3.4% 才吃单。
10. **gas limit 要给足** — Aliez：OKX DEX 建议值太低，×2 不够，改 ×4 才不报 `adaptor call failed` → [知道] 我们 BSC 走 BAW/OKX v6，失败先查 gas。
11. **报价方的话别全信** — Aliez：某 DEX「先说我们报价慢、让改，几天后又说原来是对的、让改回去」→ [知道] 滑点/报价异常时先用第二源交叉验证。
12. **大额转账先小额测试** — cjsjebf 把 100 多万 USDE 转到 Bybit 不支持的 EVM 网络，15 天才拿回 → [知道] 我们现货在 SafeTrade 内部划转，不涉及跨所提币。

## B. 单腿与残仓（13–22）

13. **撤单 ≠ 撤单成功** — 撤单请求先发出也可能留下活单；先挂新单会造成两边都成交 → [要做] 撤单后回读 `canceled` 再挂。
14. **单腿不报错，只给黄色 warning** — Younes：「transaction replaced 只是黄色警告」→ [要做] 只看 error 会漏，必须比对两边持仓。
15. **单腿后 pnl 里可能一条记录都没有** — Winnie：「合约被平、现货还在、pnl 没有任何记录」→ [已做] `reconcile_spot_gap` 以实际余额/持仓为准。
16. **bundle 查询超频会误判「失败」** — Aliez：club48 查询超频返回失败但实际成功 → 静默单腿；且 CORS 导致只能发一个 relay，单腿概率上升 → [知道] 基础设施依赖=单腿来源。
17. **两腿数量不匹配是静默的** — ⌛️：链上成交 1 笔、CEX 成交 6 笔，没报错，最下面没有交易信息 → [已做] 以持仓对账。
18. **残仓「不足一个 size」就两边同平** — ⌛️：设 A then B 后残余不足一个 size → 两边直接平，并记 idx，下一个带 size 的 idx 才允许再平 → [要做] 加 idx 去抖。
19. **现货扣手续费后每次少一点，最后一笔会失败** — neal → [要做] 平仓量按实际可用余额算，留 0.1% 余量。
20. **粉尘不清，账面永远对不平** — 我们自己的 0.46 颗挂了很久 → [已做 2026-10-31] 永续=0 且现货 ≥0.2 颗 → 市价清掉 + 推送。
21. **强平时没有「先卖后买」的选择权** — x1024 2026-09-03：合约强平成交、现货没成交，现货暴跌亏麻 → [知道] 我们「绝不先买回永续」只在主动平仓时成立，强平不受控制，只能靠保证金冗余。
22. **两边同时被平才算平完** — 群里多次单腿后手动补 → [已做] 5 秒对账 + 自动修复。

## 不适用 / 别学
