# 期现价差实战手册（跨标的可复用）

> 来源：2026-10-26 ~ 10-30 PEARL（SafeTrade 现货 ↔ HL `io:PRL` 永续）真实下单、真实亏损、真实现金对账。
> 每条都带数字，都是在账户里付过钱的。换标的（BSC 链上现货、别家 CEX 现货）照样适用。

## 0. 一句话

**进场看「收窄空间 − 手续费 − 盘口宽度」够不够，平仓只看现金流。价差 pp 只描述两条腿的相对变化，不代表钱变多。**

## 1. 成本结构（必须先算，算错就白干）

```
手续费：现货 0.1%×2 + 永续 0.009%×2 = 0.218%
盘口宽度：现货买卖价差实测 1.20% ~ 3.10%（不是 0.57% 那种理想值）
一轮盈亏 ≈ 价差收窄幅度 − 0.218 − 两边盘口宽度
```

实盘例子：收窄 1.19pp − 0.22 − 1.29 = **−0.32pp**，看着"赚了 1.19pp"，其实是白干。
推论：**价差 2.0% 进场，至少要收窄 2.1pp 才有钱**（盘口 1.4 + 费 0.22 + 利润 0.5）。

## 2. 三个把结论带偏的陷阱（都踩过）

### 陷阱 A：把「价差收窄」当收益
按 3.61% → 0.5% 推算 +$16，实际现金流 **−0.5**。
价差是报价层，钱是现金流层；中间隔着盘口宽度和部分成交。

### 陷阱 B：信任自己 state 里记的入场价差
state 写 3.61%，交易所持仓均价反推只有 **0.21%**（中间被 reconcile 重建过）。
等于"在价差几乎为 0 的位置建仓"，怎么等都等不出利润。
**规则：每轮用交易所真实持仓均价校准，并从它反推现货成本，不信本地缓存。**

### 陷阱 C：只报赚的那条腿
空头腿 +0.27U 就报"赚了"，现货腿 −1.00U 归到"历史成本另算"。
**规则：只报两腿合计现金流，单腿浮盈一律不算。**

## 3. 单腿（裸空/裸多）是最大的操作风险

事故：平仓时现货成交 200 颗，永续只平到 140 颗 → 攒出 **70 颗裸空**，最后在 1.6888 买回（建仓 1.6026），**一次确认亏损 −$6**。

规则：
- 每 5 秒对账 `|永续|` vs `现货`，偏差 > 1 颗就动**永续**补齐（用户口径：一般动永续）
- 平仓时先卖现货、再买回等量永续；现货卖光后剩余永续必须单腿买回
- 一个退出指令、单边已平、屏幕到达目标价差 —— 都不证明另一腿退出

## 4. 进场：倒金字塔（价差越大进越多）

```
≥2.0% → 40 颗 ｜ ≥2.5% → 80 ｜ ≥3.5% → 120 ｜ ≥4.5% → 160   （上限 400）
先空永续 → 立刻买等量现货 → 买不够立刻砍永续，绝不留单腿
单笔 ≤ 盘口 1% 内深度 15%（砸盘口 = 自己把价差买没）
资金费 <0.003%/h 时门槛 +0.5pp（收不到租金就要更大价差）
现货盘口宽 >1.0% 不开仓（平仓差价会天然很负）
```

## 5. 平仓：正金字塔（价差越窄平越多）+ 现金闸

```
全平线锚定历史 P5（PEARL: 0.87%），沿「入场 → P5」分 1/3、2/3、3/3
累计平仓 1/6 → 3/6 → 6/6
每刀 ≈10 USDT（≈6 颗），深度不足单量 3 倍就跳过这一刀
价差反弹回上一档之上 → 整档停手
```

**现金闸（唯一放行条件）**
```
每颗现金 = (现货卖买一 − 建仓买价) + (永续建仓卖价 − 买回卖一)
再扣 0.218% 手续费，仍为正才允许这一刀
```

## 6. 档位必须锚定历史低位，不能"入场 − 固定 pp"

PEARL 分布（1,271 分钟点）：最低 −1.09 ｜ P1 +0.21 ｜ P5 +0.87 ｜ P10 +1.30 ｜ 中位 +2.62 ｜ 最高 +7.22

| 入场 | 「−3.7pp 全平」线 | 历史达到时间占比 |
|---|---|---|
| 2.0% | −1.7% | **0.0%** |
| 2.5% | −1.2% | **0.0%** |
| 3.5% | −0.2% | 0.8% |
| 4.5% | +0.8% | 4.1% |

结论：入场越低，档位必须越浅，否则第三档永远触发不了。用 P5 当锚，档位随入场缩放。

## 7. 对账（每天必跑）

```
永续现金流 = 已实现 + 手续费 + 资金费   ← HL userFills / userFunding
现货现金流 = 卖出收入 − 买入成本        ← SafeTrade /trade/market/trades
残差 = 现金流 − 账本；|残差| > $3 先查单腿，再谈收益
```

首次对账结果：永续 −14.71、账本 +7.33、残差 **−22.05** → 账本口径系统性高估。

## 8. 上线顺序（跳步就是交学费）

1. 纸面跑通一整轮（含平仓与对账）
2. 20 颗真仓跑通一轮（真成交、真手续费、真单腿风险）
3. 才按金字塔放大
