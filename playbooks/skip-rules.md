# 不看清单（Skip Rules）

分三层：**配置自动拦**（代码里）→ **判据拦**（我判断）→ **红灯**（绝对不碰）。

## 第一层：配置自动拦（狙击器已生效）

| 条件 | 阈值 | 动作 |
|---|---|---|
| 单份成本超限 | > 0.0016 BNB | 不打 |
| 打新费过高 | > 3.0% | 不打 |
| 募集额太小/太大 | < 5 或 > 50 BNB | 不打 |
| 计价币不是 BNB | 非 BNB | 不打 |
| 仓位已满 | 已打 3 个 | 不再打 |
| 总预算超限 | 累计 + 本次 > 0.005 BNB | 不打 |
| 链上 `previewMint` 返回 accepted=0 | 满了/毕业/超 cap | 不打 |

## 第二层：判据拦（我判断，不自动）

| 情况 | 为什么 | 怎么处理 |
|---|---|---|
| **没有二级市场/看不到地板价** | 利润必须有人接盘 | 只领免费张 |
| **地板价 < 2 倍铸造总成本** | 风险收益不划算 | 不打付费张 |
| **全站同赛道 24h 成交量中位数 0**（如 Gang 内盘） | 买盘不存在 | 只做验证，不重仓 |
| **曲线盘（bonding curve）非固定价** | 我们没速度优势，靠判断 | 不碰，留给人工 |
| **群里传的"创业盘"，无官方背书** | 89 枚赚 1.48U 的教训 | 只领免费 |
| **持有人 < 10 且成交量 0** | 没有真实需求 | 不打 |
| **需要全局无限授权** | 风险面 = 授权面 | 放弃或改逐枚授权 |

## 第三层：红灯（绝对不碰）

1. **要私钥/助记词**的 —— 一律拒绝（BAW 托管就是为避免这个）
2. **要你转账到个人地址**的"预留名额"
3. **陌生链接直连钱包**、非官方域名（如 gang.fun 之外的仿站）
4. **声称"稳赚/内幕/白名单保证"** 的私聊
5. **打新费 > 5%** 或**取出费异常**（撤回收费变高的项目）
6. 任何**"先付 gas 到某地址"**的 mint

## 一句话判据

> **看盘先看退出，不看入口。**
> 卖不掉的东西，多便宜都是贵的。
