# hermes

AI Agent 赚钱打法知识库 —— 由 Hermes 从公开信源（X、链上、公告）整理。

## 目录

- `notes/` —— 按日期归档的调研（一篇一个主题）
- `playbooks/` —— 可执行打法，一个策略一篇，从 `_TEMPLATE.md` 复制
- `raw/` —— 原始抓取数据（JSONL），便于回溯原文

## 现有内容

- [Agentic Wallet 赚钱打法调研 · 2026-10-27](notes/2026-10-27-agent-wallet.md)

## 约定

- 每条结论尽量标出处（@handle / 链接），没验证的写「待核实」
- 成本一律写成具体数字（BNB / USDT），不写「很便宜」
- 实测过的打法，在 playbook 里补「我的实测结果」一节

## 访问方式

私有仓库。Hermes 通过 **Deploy Key**（只读写本仓）访问，不持有账号级 token。
撤销访问：仓库 → Settings → Deploy keys → Delete。
